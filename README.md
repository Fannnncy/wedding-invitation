# Wedding 本地婚礼邀请函

一套可直接本地预览的星露谷像素风电子请柬，包含宾客填写页和管理后台。当前版本不需要部署、不依赖数据库：登记信息仅保存在**当前浏览器**的 Local Storage 中，适合本机演示和页面确认。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址即可查看邀请函；管理后台地址为 `http://localhost:5173/admin/`。

先在邀请函填写“确认赴约”，然后刷新管理后台即可查看统计、筛选及导出 CSV。无痕窗口、不同浏览器或不同设备不会共享数据。

## 修改婚礼信息

打开 [app.js](app.js)，在顶部 `weddingConfig` 中修改新人姓名、婚礼日期、地点、地图链接和当天流程。所有页面文本、倒计时和日历会随之更新。

## 本地登记模式

`config/rsvp.json` 已设为：

```json
{ "enabled": true, "mode": "local" }
```

本地模式不提供密码保护，也不应将其作为真实婚礼的线上收集系统。若将来需要线上收集，再接入服务器和数据库，并将 `mode` 改为远程接口模式。

## 常用入口

- 邀请函：`/`
- 宾客管理：`/admin/`
- 配置：`app.js`
- RSVP 模式：`config/rsvp.json`
